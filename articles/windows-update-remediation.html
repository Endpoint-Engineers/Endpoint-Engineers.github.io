Windows Update Remediation with PowerShell + Intune

Published: August 31, 2026

Windows Update failures are one of the most common endpoint management problems in enterprise environments. Instead of manually troubleshooting every device, we can use PowerShell and Microsoft Intune Remediations to automatically detect and resolve common Windows Update issues.

What does this solution do?

  • Checks Windows Update services
  • Checks BITS
  • Checks Cryptographic Services
  • Resets Windows Update cache
  • Resets Catroot2
  • Restarts required services
  • Triggers a Windows Update scan
  • Creates a local remediation log

Architecture

Detection Script → Problem Found → Remediation Script → Service Repair → Cache Reset → Windows Update Scan → Verification
